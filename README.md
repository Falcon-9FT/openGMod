# openGMOD

**openGMOD** — реимплементация движка Garry's Mod с нуля на Rust, по примеру
[OpenMW](https://openmw.org) и [openOMSI](https://github.com/turbo-devv/openOMSI). Цель — 64-битный
многопоточный движок с современным рендером (wgpu: DirectX 12, запасной — Vulkan), на котором
работают контент, Lua-аддоны, геймоды и воркшоп Garry's Mod без изменений. Сейчас — под Windows;
Linux и macOS — позже.

> [!IMPORTANT]
> **Нужна лицензионная Garry's Mod.** В openGMOD нет игрового контента: он работает на файлах
> установленной игры и на аддонах воркшопа, на которые подписан её владелец. **Папку игры
> openGMOD только читает** — ничего в ней не создаёт и не меняет.

> [!WARNING]
> **Ранняя стадия.** Готово чтение контента. В `opengmod` по карте ходит игрок одиночной игры:
> работает Lua сервера с геймодом `sandbox` и аддонами, оружие, урон, энтити карты и SENT,
> их модели видны в мире, пропы падают и ложатся по своей физике, физган их носит и
> замораживает, тулган сваривает их, вешает на верёвки и ставит на оси. Рядом работает Lua
> клиента: HUD, меню спавна (Q) и контекстное меню (C) — Derma из игры; щелчок по пропу в меню
> его спавнит. Есть звук: звуки Lua и оружия, шаги по поверхностям, удары пропов (пока только
> на Windows). Пока нет анимации моделей, своих иконок моделей, чата, HTML-панелей и
> мультиплеера. Что дальше — в [дорожной карте](docs/ROADMAP.md).

## Что уже есть

| Crate | Что делает |
|---|---|
| [`gmod-fs`](crates/gmod-fs) | находит GMod (указанная папка, `GMOD_ROOT`, библиотеки Steam), читает VPK и GMA и собирает файловую систему так же, как GMod: `gameinfo.txt`, подписки воркшопа (включая старые сжатые `.bin`), аддоны из `garrysmod/addons`, игры из `cfg/mount.cfg` |
| [`gmod-kv`](crates/gmod-kv) | KeyValues: материалы `.vmt`, скрипты, VGUI `.res`, локализация, файлы Steam |
| [`gmod-glua`](crates/gmod-glua) | диалект Lua из GMod (`!=`, `!`, `&&`, `\|\|`, `//`, `/* */`, `continue`, `DEFINE_BASECLASS`) → обычный LuaJIT, строка в строку |
| [`gmod-lua`](crates/gmod-lua) | Lua-рантайм: LuaJIT 2.1, реалмы, загрузчик GMod (`include`, `require`, `AddCSLuaFile`), песочница без байткода, запуск геймода, библиотеки движка (`Vector`, `Angle`, `timer`, ConVar'ы, `file`, `util`, `net`...), энтити и SENT, энтити карты, игроки, оружие, урон, трассировки, физика (`PhysObj`), физган, констрейнты, ввод энтити (`Input`, `Fire`); клиент: `surface` и шрифты, VGUI-панели, на которых стоит Derma, HUD движка, клавиши, мышь и бинды, энтити сервера с их сетевыми переменными |
| [`gmod-bsp`](crates/gmod-bsp) | карты BSP v19–21: все нужные для отрисовки лампы, дисплейсменты, статические пропы, pakfile; сетка мира с атласом световых карт; что в карте твёрдое (браши, дерево BSP, дисплейсменты, брашевые энтити) и трассировки луча и коробки, как `util.TraceLine` и `util.TraceHull` |
| [`gmod-material`](crates/gmod-material) | текстуры VTF 7.0–7.5 (все 30 форматов пикселей, DXT, кубмапы, анимация), материалы VMT (параметры шейдеров, условия, патч-материалы) и картинки PNG (иконки, скин Derma) |
| [`gmod-model`](crates/gmod-model) | модели MDL + VVD + VTX: кости, скины, бодигруппы, сетки для отрисовки; запечённый свет статических пропов (VHV); физические модели PHY: выпуклые куски, массы, поверхности, суставы рэгдоллов |
| [`gmod-world`](crates/gmod-world) | карта, готовая к отрисовке: мир, брашевые энтити и статические пропы по материалам, их свет, текстуры, небо; раскладка для видеокарты; что в карте твёрдое, пропы по их `.phy` |
| [`gmod-physics`](crates/gmod-physics) | физика пропов на Rapier: тела из выпуклых кусков `.phy` с их массой и затуханием, мир из брашей, дисплейсментов и статических пропов карты, гравитация, сон, толчки и вращение в единицах GMod; суставы — сварка, шарнир, ось, слайдер, верёвка, пружина, no-collide — с пределом прочности |
| [`gmod-movement`](crates/gmod-movement) | движение игрока, как в Source: трение и ускорение, ходьба и бег, ступеньки, склоны, скольжение по стенам, прыжок, приседание, падение, плавание |
| [`gmod-audio`](crates/gmod-audio) | звук, как его играет Source: WAV (PCM, ADPCM, петли из `cue`), MP3, OGG; звуковые скрипты `game_sounds`; микшер, который ставит звук в мир по уровню в децибелах и панорамирует от камеры |
| [`gmod-ui`](crates/gmod-ui) | 2D, каким его рисует GMod: шрифты `surface.CreateFont` из файлов игры и системы (размер, жирность, тень, обводка, размытие, строки развёртки) и кадр из прямоугольников, картинок и текста, обрезанных по панелям |
| [`gmod-render`](crates/gmod-render) | рендер на wgpu: DirectX 12, запасной — Vulkan; текстуры DXT уходят на видеокарту без распаковки; модели энтити там, где они стоят; 2D клиента (HUD, панели) поверх картинки |
| [`gmod-app`](crates/gmod-app) | программа `opengmod`: окно, карта и игра в ней — Lua сервера с `sandbox` и аддонами, игрок, Lua клиента с HUD и меню, консоль в терминале |
| [`gmod-check`](tools/gmod-check) | проверка вашей установки: что openGMOD уже умеет прочитать; картинка карты без видеокарты; трассировки по карте, как в игре |

Проверено на настоящих данных. Все 596 Lua-файлов GMod после перевода компилируются в LuaJIT
2.0 и 2.1. Lua актуальной GMod (репозиторий Facepunch/garrysmod) на сервере загружается целиком:
`includes/init.lua`, autorun, геймоды `base` и `sandbox`, их энтити и оружие — 196 файлов без
единой ошибки; на клиенте — тоже без ошибок, вместе с Derma, HUD и меню спавна. Тестовые VPK,
собранные инструментами Valve, читаются с совпадающими CRC. Карта TF2 читается целиком,
286 текстур из неё и из репозитория GMod декодируются, DXT совпадает с декодером ImageMagick с
точностью до округления.

## Открыть карту

**На Windows:** скачайте `opengmod.exe` со страницы
[Releases](https://github.com/Falcon-9FT/openGMod/releases) и запустите двойным щелчком —
откроется `gm_construct`. Другая карта — `opengmod.exe gm_flatgrass` или файл `.bsp`,
перетащенный на программу.

Управление: щелчок по окну — мышь управляет взглядом, Esc — отпустить мышь; W A S D — ходьба,
Shift — бег, Alt — медленно, пробел — прыжок, Ctrl — присесть; левая и правая кнопки мыши —
стрелять, R — перезарядка, E — использовать, F — фонарик; 1–6 и колесо мыши — выбор оружия;
Z — отменить последнее (`gmod_undo`); V — полёт сквозь стены (noclip) и обратно; Q (держать) —
меню спавна, C (держать) — контекстное меню: пока меню открыто, мышь водит курсором и нажимает
в меню; F11 — во весь экран; F12 — снимок экрана в `~/.opengmod/screenshots`. С физганом:
держать левую кнопку — нести проп, колесо — дальше или ближе, E и мышь — повернуть, правая
кнопка — заморозить, R — разморозить. С тулганом: левая кнопка — применить инструмент,
правая — его второе действие, R — сбросить.

В карте работает сама игра: Lua сервера — `includes/init.lua`, autorun, геймод `sandbox` и Lua
ваших аддонов из воркшопа, как их запускает GMod. Игрок одиночной игры заходит, спавнится с
оружием sandbox и ходит через хуки геймода (`SetupMove`, `Move`...), так что аддоны, которые
меняют движение, работают. Что Lua печатает и ошибки аддонов видны в терминале, а строки,
набранные в нём, — консоль игры от лица игрока: `give weapon_crowbar`, `gm_spawn
models/props_c17/oildrum001.mdl`, `noclip`, `kill`, `lua_run <код>`, команды аддонов. Энтити с
моделями — пропы, SENT аддонов, NPC, оружие на земле — видны там, где их держит Lua, но пока
в позе, в которой модель сделана, и без оружия в руках. Пропы падают, катятся и ложатся по
своим физическим моделям (`.phy`), пропы карты стоят замороженными, если так указано в карте.
Физган берёт, носит, вертит и замораживает их через хуки геймода (`PhysgunPickup`,
`OnPhysgunFreeze`...), как в GMod. Тулган — тот, что в sandbox, со всеми его инструментами: их
список и настройки — в меню спавна, а в консоли можно выбрать инструмент (`gmod_toolmode weld`,
`rope`, `axis`, `ballsocket`, `slider`, `elastic`, `nocollide`, `remover`...) и задать его
настройки (`weld_forcelimit 2000`). Сварка, верёвки, оси, шарниры, слайдеры и резинки держат
пропы суставами физики и рвутся, если тянуть сильнее заданного. `--no-lua` — только ходьба по
карте, без игры.

Рядом с сервером работает Lua клиента — тот же, что у игрока в GMod: каждый кадр он получает
от сервера энтити с их сетевыми переменными, рисует поверх мира HUD Half-Life 2 в том виде,
какой оставляет GMod (здоровье, броня, патроны, прицел — каждое по `HUDShouldDraw`), и то, что
рисует сам (`HUDPaint`, уведомления), а команды, которых не знает, отправляет серверу. Клавиши
сначала идут к его панелям и биндам, поэтому Q и C открывают меню спавна и контекстное меню из
Derma игры: дерево спавнлистов, вкладки, панель инструментов, строку меню. Щелчок по пропу в
меню спавнит его (`gm_spawn`, как в GMod). Иконки моделей — готовые картинки, которые
нарисовала сама GMod (`materials/spawnicons`); своих openGMOD пока не рисует, поэтому иконки
моделей, которых GMod ещё не показывала, пустые, хотя щелчок по ним работает. Нет чата
(`chat.AddText` печатает в терминал) и HTML-панелей (`DHTML`, MOTD).

```sh
cargo run --release -p gmod-app                       # gm_construct
cargo run --release -p gmod-app -- gm_flatgrass --gmod "D:\SteamLibrary\steamapps\common\GarrysMod"
```

Видно мир, брашевые энтити и статические пропы с текстурами, световыми картами и запечённым
светом пропов, смешивание текстур на рельефе, прозрачность, воду и небо; модели энтити
освещены сверху, без света карты. Пока нет декалей, 3D-скайбокса, тумана, отражений и карт
нормалей.

Игрок появляется в точке старта карты (её выбирает геймод) и ходит, как в GMod: 66⅔ тактов в секунду, упирается в
стены и скользит вдоль них, шагает по ступенькам до 18 юнитов, съезжает со склонов круче 45°,
прыгает, приседает и пролезает под низким, плавает в воде, лазает по лестницам (браши
`tools/toolsinvisibleladder` и `func_ladder`; прыжок отталкивает от лестницы). Твёрдое — браши мира, дисплейсменты,
брашевые энтити (двери, `func_brush`) и статические пропы — по своим физическим моделям
(`.phy`) или габаритной коробке, как указано в карте. Энтити (пропы и другие) твёрды для игрока
своей габаритной коробкой, толкать пропы он пока не может; лестниц HL2, на которые встают
кнопкой E (`func_useableladder`), пока нет.

## Проверить свою установку

**Проще всего на Windows:**
1. Скачайте `gmod-check.exe` со страницы [Releases](https://github.com/Falcon-9FT/openGMod/releases).
2. Запустите его двойным щелчком (или перетащите на него папку `GarrysMod`).
3. Отчёт сохранится рядом с программой в `gmod-check-report.txt`.

Из исходников нужен [Rust](https://rustup.rs) 1.89 или новее:

```sh
cargo run --release -p gmod-check                     # найдёт GMod через Steam и проверит всё
cargo run --release -p gmod-check -- --gmod "D:\SteamLibrary\steamapps\common\GarrysMod"
cargo run --release -p gmod-check -- info             # что смонтировано и в каком порядке
cargo run --release -p gmod-check -- ls lua/autorun   # папка игровой файловой системы
cargo run --release -p gmod-check -- find "maps/*.bsp"
cargo run --release -p gmod-check -- glua lua/includes/init.lua   # Lua так, как его увидит LuaJIT
cargo run --release -p gmod-check -- lua                          # запустить Lua сервера и sandbox
cargo run --release -p gmod-check -- lua client --all             # клиент; все недостающие функции
cargo run --release -p gmod-check -- --crc            # плюс проверка CRC каждого файла архивов
cargo run --release -p gmod-check -- render gm_construct          # картинка карты в gm_construct.png
cargo run --release -p gmod-check -- render gm_flatgrass --from 0,0,200 --to 800,0,100 --size 1920x1080
cargo run --release -p gmod-check -- trace gm_flatgrass --from 0,0,100 --to 0,0,-1000  # как util.TraceLine
cargo run --release -p gmod-check -- trace gm_flatgrass --from 0,0,100 --to 0,0,-1000 --mins -16,-16,0 --maxs 16,16,72 --mask 33636363
```

`gmod-check` читает каждый файл, для которого в openGMOD уже есть читатель (архивы,
KeyValues, весь Lua, текстуры, материалы, модели и карты, включая аддоны воркшопа), и печатает отчёт со
списком ошибок. Если что-то не прочиталось, пришлите отчёт — по нему чинятся читатели. Отдельно
отчёт перечисляет, чего не хватает в самом контенте: текстуры, на которые ссылаются материалы, и
материалы и модели, на которые ссылаются карты (обычно — из игр, которые не подключены). Старые сжатые загрузки воркшопа
(`.bin`) распаковываются в `~/.opengmod/cache/workshop`, а не в папку игры (`--no-unpack`
отключает распаковку).

`lua` запускает Lua игры так, как это делает движок: `includes/init.lua`, autorun, геймод
`sandbox` с базовым, энтити и оружие, хуки до `Initialize` и секунду игрового времени; с
`--map` — ещё энтити карты и игрока, который заходит и спавнится. Он печатает ошибки скриптов
(как консоль GMod), глобальные функции, которых не хватило, где игрок оказался и что у него в
руках, и сколько функций API из вики GMod уже есть в этом реалме. Файлы, которые Lua пишет (`file.Write`),
попадают в `~/.opengmod/data`. `lua client` запускает Lua клиента с сервером за ним и играет
секунду кадров: HUD и панели рисуются, по дороге открываются меню спавна и контекстное меню и
нажимается первый проп меню спавна, а отчёт говорит, сколько панелей было с каждым меню,
появился ли проп на сервере и сколько ошибок было у сервера.

`render` рисует карту на процессоре и сохраняет PNG — то же, что видно в `opengmod`, но без
видеокарты: для проверки и для машин без DirectX 12 и Vulkan. Без `--from` камера встаёт на
точку появления игрока.

`trace` проводит трассировку так же, как `util.TraceLine` в игре (с `--mins` и `--maxs` — как
`util.TraceHull`, `--mask` — числа `MASK_` из GMod), и печатает те же поля, что `TraceResult`.
То же самое в GMod — в консоли игры: `lua_run PrintTable(util.TraceLine({start = Vector(0, 0,
100), endpos = Vector(0, 0, -1000)}))`; где вы стоите, печатает `getpos`. Если числа
расходятся, пришлите обе распечатки.

Строка `Physics` в отчёте — сколько физических моделей (`.phy`) прочиталось. Строка
`Collision` — на скольких картах игрок, поставленный в точку появления, устоял: не застрял в
стене и не провалился сквозь пол (пропы карты твёрдые).

## Сборка и тесты

```sh
cargo build --release
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

Внешние зависимости есть у рендера и окна (`gmod-render`, `gmod-app`: wgpu и winit) и у
Lua-рантайма (`gmod-lua`: mlua, rusqlite и ureq с rustls для `HTTP`; LuaJIT, SQLite и ring
собираются из исходников компилятором C, на Windows — MSVC), у физики (`gmod-physics`: Rapier,
чистый Rust), у 2D (`gmod-ui`: fontdue и ttf-parser, чистый Rust) и у звука (`gmod-audio`:
Symphonia, чистый Rust; вывод в `gmod-app` — cpal, на Windows). Остальные crate'ы обходятся
стандартной библиотекой.
